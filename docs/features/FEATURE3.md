# Feature 3: Skills

## What it does
A grouped list of skills shown as tags under category headings, for example:
- Languages
- Frameworks / Libraries
- Cloud / DevOps
- Tools
- Customer-facing skills (e.g. integrations, debugging with customers, communication) – useful for FDE roles

## Rules
- Data comes from `src/data/skills.ts` as `{ category, items[] }`
- Categories and items are placeholders until I provide them

## Done when
- [ ] Each category shows its heading and tags
- [ ] Adding a category in the data file shows it on the page
