# Architecture

## Stack
- Language: TypeScript
- Framework: Next.js (App Router)
- Styling: Tailwind CSS (dark mode via class)
- Database: none
- Form handling: Formspree (client posts directly to Formspree endpoint)
- Hosting: Vercel (free `vercel.app` domain first)

## Folder structure
```
src/
  app/
    layout.tsx       fonts, metadata, theme provider
    page.tsx         the single page; renders all sections in order
    sitemap.ts       sitemap
  components/        Nav, ThemeToggle, Hero, About, Skills, Projects, Experience, Contact, Footer
  data/              all content: profile, skills, projects, experience, links
public/
  resume.pdf         downloadable resume
  (social preview image is generated by src/app/opengraph-image.tsx)
  images/            project screenshots (add when needed)
tests/               tests
docs/                project docs
```

## How it works
Visitor → one Next.js page → sections read content from `src/data/` → contact form posts straight to Formspree → Formspree emails me.
No backend and no database of our own.

## Key points
- Sections are anchors (`#about`, `#skills`, `#projects`, `#experience`, `#contact`); nav uses smooth scroll.
- Theme: dark by default, toggle stored in `localStorage`; set before paint to avoid flash.
- Project links (Notion, GitHub, Live) are optional fields; the UI hides any that are empty.
- Formspree form ID goes in an env var (`NEXT_PUBLIC_FORMSPREE_ID`), not hard-coded.
- No analytics.
